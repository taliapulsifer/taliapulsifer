## Featured projects

### 🌎 North American Earthquake & Geology Explorer

An interactive map combining earthquake records, classified fault sources, and dominant state-level geology.

- Integrates USGS earthquake, fault, and geology data with geographic boundaries.
- Uses area-weighted spatial analysis to identify dominant lithology within each state.
- Uses concurrent downloads, local caching, and state-by-state processing to handle large datasets.
- Presents results through selectable map layers and interactive popups.

**Built with:** Python, GeoPandas, Pandas, Folium/Leaflet, Requests, and Matplotlib.

[Explore the map](https://taliapulsifer.github.io/Map_Project/) · [View the code](https://github.com/taliapulsifer/Map_Project)

*The published map is a generated snapshot rather than a live earthquake feed.*
